# Monopod — спецификация

Личный музыкальный плеер для Android в стиле iPod Classic. Управление только колесом прокрутки, как на оригинале.

## Решения

| Тема | Решение |
|---|---|
| Источник музыки | Только локальные файлы. Пользователь вручную выбирает папки (SAF), сканируются только они |
| Платформа | Android 16+ (minSdk 36), Kotlin, Jetpack Compose, Media3 (ExoPlayer + MediaSessionService) |
| Раскладка | Выбор в настройках: «классика» (экран ~40% + большое колесо), «большой экран» (~60%), «колесо прячется» |
| Эффект экрана | Настраиваемый: цветной LCD + scanlines / сильный CRT (мерцание, изгиб, бегущая полоса) / монохромный LCD с пиксельной сеткой; ползунок интенсивности. Реализация через AGSL `RuntimeShader` |
| Корпус | Несколько тем: белый, чёрный (U2, красный акцент), серебристый алюминий, цветные (mini/nano) |
| Шрифт | Выбор в настройках: свободный аналог Chicago/Myriad с кириллицей или пиксельный bitmap-шрифт |
| Язык | Русский и английский, по языку системы |
| Управление | **Только колесо**: экран не реагирует на касания. Кольцо — прокрутка, центр — выбор, MENU — назад (долгое нажатие на MENU — в корень), ⏮/⏭ — предыдущий/следующий (долгое — перемотка), ⏯ — пауза |
| Отклик колеса | Вибрация (Haptics API, короткий тик на шаг) + звук щелчка; оба отключаются в настройках |
| Now Playing | Как в оригинале: кольцо — громкость; центр по кругу переключает режимы: перемотка → рейтинг/шаффл → текст песни |
| Cover Flow | Пункт в меню Music + автоматически в горизонтальной ориентации на весь экран; листается колесом |
| Тексты | Из тегов (USLT/SYLT) или из `.lrc` рядом с файлом, синхронная прокрутка |
| Эквалайзер | Пресеты как в iPod (Rock, Bass Booster, Vocal Booster…) + свой |
| Звук | Gapless, crossfade (настраиваемая длительность), ReplayGain (track/album), таймер сна |
| Вне приложения | Уведомление и медиаконтролы на экране блокировки, Bluetooth/кнопки гарнитуры, виджет «мини-iPod» на рабочий стол |
| Не делаем в v1 | Стриминг, свой сервер, Android Auto, Last.fm, создание плейлистов |

## Меню (как в iPod Classic)

```
Monopod
├── Music
│   ├── Cover Flow
│   ├── Playlists      (чтение .m3u из выбранных папок)
│   ├── Artists → Albums → Songs
│   ├── Albums → Songs
│   ├── Songs
│   └── Genres
├── Shuffle Songs
├── Now Playing        (только когда что-то играет)
└── Settings
    ├── Shuffle / Repeat
    ├── EQ
    ├── Sound (Crossfade, ReplayGain, Gapless)
    ├── Sleep Timer
    ├── Library Folders / Rescan
    ├── Appearance (тема корпуса, раскладка, эффект экрана, шрифт)
    ├── Clicker (звук / вибрация)
    └── About
```

## Этапы

1. ✅ **Каркас и колесо.** Проект Compose, корпус, экран, компонент колеса (жесты по кольцу, шаги, вибрация и звук), навигация по меню-стеку, кнопки колеса. Список-заглушка. Настройки пока в памяти, сохранение будет на этапе 4.
2. ✅ **Библиотека.** Выбор папок, сканирование, теги и обложки (Room-индекс), меню Artists/Albums/Songs/Genres/Playlists. Папки — это сохранённые SAF-разрешения; повторное сканирование читает только новые и изменённые файлы.
3. ✅ **Воспроизведение.** Media3-сервис, очередь, shuffle/repeat, Now Playing с режимами центра, уведомление и экран блокировки, кнопки гарнитуры. Центр в Now Playing: громкость → перемотка → перемешивание (текст песни добавится на этапе 6, рейтинга пока нет). Очередь и позиция восстанавливаются после перезапуска.
4. ✅ **Экран.** AGSL-шейдеры ряби и scanlines, темы корпуса, раскладки, шрифты, экран настроек Appearance. Эффекты: цветной LCD, ЭЛТ (анимирован), монохром; сила 0–100%. Раскладки: классика, большой экран, весь экран (колесо поверх экрана). Шрифты: классика, пиксельный (Tiny5, OFL), моно. Все настройки сохраняются.
5. ✅ **Звук.** Gapless, crossfade, ReplayGain, эквалайзер, таймер сна. Плавный переход вторым «хвостовым» плеером (2–12 с), выравнивание громкости по ReplayGain/R128 (ID3, Vorbis, MP4; только приглушение), 21 пресет iPod + свой 5-полосный, таймер сна 15–120 мин с затуханием за 30 с и «Конец песни». Gapless — штатный ExoPlayer, когда переход выключен.
6. ✅ **Cover Flow и тексты.** 3D-обложки, переход в ландшафт, тексты из тегов и `.lrc`. Cover Flow: 3D-обложки с отражениями, переворот к списку песен, на весь экран при повороте телефона (колесо справа). Тексты: .lrc рядом с песней (UTF-8 или cp1251) или тег USLT/Vorbis/MP4; синхронные подсвечивают строку, обычные листаются колесом.
7. ✅ **Виджет и полировка.** Виджет на рабочий стол (Glance), локализация, производительность и батарея. Иконка (адаптивная + монохромная), виджет «мини-iPod» 4×2 с ⏮ ⏯ ⏭, без опроса в фоне и на паузе, релизная сборка с R8 (4,3 МБ), README.

Каждый этап считается готовым только после проверки на эмуляторе или устройстве.

## Версия 1.1

Решения: тёмная тема — только экран (Вкл / Выкл / Как в системе); экран «как на фото» (iPod nano 3G) — внутри Cover Flow после выбора песни; наклейки — из готовых PNG с прозрачностью, белая обводка генерируется; зажатие центра — не делаем.

### Этапы 1.1

1. ✅ **Мелочи.** Удалить виджет; скрытие верхней полосы телефона (статус-бара) в настройках; настоящий заряд батареи; сила вибрации колеса; значки 🔀 и 🔁/🔂 в статус-баре экрана.
2. ✅ **Тёмная тема экрана.** Тёмные меню и «Сейчас играет», выбор Вкл / Выкл / Как в системе.
3. ✅ **Быстрые настройки по зажатию ⏯.** Панель снизу: Перемешивание, Повтор, Таймер сна, Плавный переход, Эквалайзер (выравнивание громкости — только в Настройках). Эквалайзер: стандартные пресеты можно удалять (и восстановить), свой пресет — сохранять как «Мой пресет N». Колесо выбирает строку, центр включает изменение (‹ значение ›), колесо меняет, центр — готово; MENU или повторное зажатие ⏯ закрывает, через 5 с бездействия закрывается сама. Перемешивание уходит из режимов центра в «Сейчас играет».
4. ✅ **Ускорение колеса.** Быстрая прокрутка прыгает сильнее, поверх длинного списка большая буква.
5. ✅ **Статистика и рейтинг.** Счётчик прослушиваний; умные плейлисты «Топ-25», «Недавно добавленные», «Недавно игравшие»; рейтинг ★★★★★ режимом центра в «Сейчас играет».
6. ✅ **Cover Flow: сейчас играет.** После выбора песни остаёмся в Cover Flow, экран в стиле iPod nano 3G (обложка, название / артист / альбом, «1 из N», прогресс) и анимация смены песни.
7. ✅ **Наклейки на корпус.** PNG из галереи, белая обводка по контуру, редактор с тачскрином (двигать, масштабировать, поворачивать, удалять), нельзя на экран и колесо, сохраняются.

### 1.1.1 — правки

- Иконка: минималистичное кольцо с центром.
- Наклейки проходят под экраном и колесом (заходящая часть обрезается), двигаются свободно.
- Прокрутка: скорость растёт плавно вместе со скоростью вращения (списки от 20 пунктов).
- Вибрация: импульс с амплитудой вместо примитива (на многих телефонах сила примитива игнорируется); режим, длительность, канал.
- Режим разработчика: сила эффекта до 1000%, скорость ряби ЭЛТ, вибрация (сила, тип, длительность, канал, что умеет мотор), градусы колеса на щелчок, сила ускорения прокрутки, громкость щелчка, сброс.

- Корпуса: Пастель mini (рамка экрана в тон), Керамика (матовая, хромовый кант, колесо-гравировка), Nano 3G.

### 1.2.0 — стиль Material

Настройки → Внешний вид → Стиль: iPod / Material. Material — тот же экран и колесо в цветах Material 3: схема из обложки играющего альбома (Palette + MaterialKolor) или из обоев (Material You), Цвета: Из обложки / Из системы. Системный шрифт, экран-карточка 28dp, выделение «таблеткой», колесо с иконками и FAB в центре (скруглённый квадрат в меню, круг в плеере, значок по действию), корпус в цветах темы, эффекты экрана и наклейки работают. Плеер: большая скруглённая обложка, волнистый прогресс (волна бежит при игре). Cover Flow: карусель M3 — соседние обложки «пилюлями», раскрываются при листании.

### Spotify

Пункт «Spotify» с зелёной иконкой в главном меню. Вход через браузер (PKCE, без секрета, `monopod://spotify-callback`), токен обновляется сам. Внутри только прослушивание, без поиска: Главная (Недавно игравшее, Топ-треки, Любимые треки) и Мои плейлисты, Выйти. Списки — Web API, играет установленное приложение Spotify через App Remote SDK 0.8.0 (нужен Premium): плейлист играет целиком с выбранной песни, остальные списки — песня + 30 следующих в очередь. Свой экран «Сейчас играет»: обложка, прогресс, колесо — громкость, центр — перемотка; ⏮⏭⏯ идут в Spotify, пока играет он; локальная музыка и Spotify ставят друг друга на паузу. Алгоритмических подборок Spotify для новых приложений нет.

### Правки после Spotify

- Spotify (1.3.2): «Мои плейлисты» — вся медиатека: Любимые треки (обложка с сердцем как в Spotify), все плейлисты (включая «Открытия недели», «Радар новинок» и др.), сохранённые альбомы, исполнители (нужен повторный вход, scope user-follow-read). «Рекомендации» — главная страница Spotify через App Remote ContentApi с настоящими обложками (нужно установленное приложение Spotify). Списки, которые Web API не отдаёт, показывают «▶ Воспроизвести» и играют целиком. Обложка → песни на обороте → Spotify «Сейчас играет».
- Перемешивание и повтор, пока играет Spotify, управляют самим Spotify.
- Акцентный цвет для стиля iPod, как в macOS: Разноцветный (классический синий), синий, фиолетовый, розовый, красный, оранжевый, жёлтый, зелёный, графит.
- Material: значки статус-бара (▶, перемешивание, повтор, батарея) в стиле Material, центральная кнопка — простой акцентный круг, скругления мягче.
- Пресеты (1.3.1): Внешний вид → Пресеты — 6 слотов 3×2 со снимком приложения. Хранят всё из «Внешнего вида» и наклейки на своих местах. Центр на пустом слоте сохраняет, на занятом применяет; если текущий вид нигде не сохранён — «Сохранить текущую тему?» Да (выбрать слот, затем применяется выбранный) / Нет. Удержание центра: Перезаписать / Удалить.

### 1.4.0 — Яндекс Музыка и «Онлайн музыка»

- Яндекс Музыка через неофициальный API (как Cassette / yandex-music-api): вход на странице Яндекса в WebView (client_id официального приложения), токен в настройках. Меню: Моя волна (бесконечная, догружается в конце очереди), Мои плейлисты (Мне нравится, свои и лайкнутые плейлисты, альбомы, исполнители), Рекомендации (персональные плейлисты с главной), Выйти — в Cover Flow. Песни играет наш плеер (ссылка на поток берётся при старте трека: yandex://track/ID), работают эквалайзер, переход, обложки, Material-цвета и тексты (LRC/текст из API).
- Настройки → Режим разработчика → Онлайн музыка: галочки Spotify и Яндекс Музыка (с иконками), по умолчанию включены. Снятие галочки выходит из аккаунта, стирает кеш (и cookies входа Яндекса), очищает очередь с песнями сервиса и убирает пункт из главного меню.

### 1.4.1 — анимация Cover Flow

- iPod-стиль: после выбора песни обложка делает полтора оборота (со стороны списка к лицевой), уменьшается и уезжает к левому краю экрана «Сейчас играет» под лёгким наклоном (24°); остальные обложки и подпись гаснут, фон переходит в цвет экрана, текст и прогресс проявляются. MENU — то же в обратную сторону: обложка возвращается в центр на список песен с выделенной играющей песней; второй MENU закрывает список. Material — прежняя карусель.
- Исправлено: при выходе из списка песен обложка пропадала на полсекунды (обратная сторона рисовалась пустой).

### 1.5.0

- Cover Flow (iPod): отражения снова видны (и у летящей обложки, и на экране «Сейчас играет»), полёт — один полуоборот от списка к лицевой стороне. На экране «Сейчас играет» в Cover Flow центр переключает режимы как в обычном «Сейчас играет»: громкость → перемотка → рейтинг → текст (синхронный прокручивается сам). То же для Яндекс Музыки и Spotify (у Spotify нет рейтинга и текстов).
- Перемотка: круглый ползунок крупнее полоски (и в Material); полоска громкости того же размера и на том же месте, что прогресс, динамики под ней.
- Внешний вид: «Цвета» — один пункт. iPod: Из обложки (меняется только акцент) / Разноцветный / … / Графит; Material: Из обложки / Из системы. В Material скрыты Корпус и Шрифт.
- Списки «Альбомы» и альбомы артиста — экран пополам: справа обложка выбранного альбома с плавной сменой, у «Все песни» обложки по очереди.
- Режим разработчика → «Объединять альбомы»: альбомы с одинаковым названием и хотя бы одним общим исполнителем (через , ; & / x feat. ft.) — один альбом.
- Пастель mini: рамка рисуется снаружи, экран того же размера, что у остальных корпусов.

### 1.5.1

- Cover Flow (iPod): прилетевшая обложка остаётся обложкой экрана «Сейчас играет» — без подмены, наклон и отражение не сбрасываются.
- Spotify: «Любимые треки» играют как коллекция Spotify (spotify:user:ID:collection), ⏮/⏭ идут по ней, а не возвращают к первой включённой песне; если Spotify не может начать с нужной песни — песня + очередь. Полки Spotify и Яндекса создаются заново при каждом входе (раньше повторный вход очищал общий список под уходящей страницей — вероятная причина вылета).
- Режим разработчика → «Последний сбой»: текст последнего вылета (files/last_crash.txt).

### 1.5.2

- Cover Flow: приземлившаяся обложка показывает обложку играющей песни (плавно сменяется при переключении), а не плейлиста — для плейлистов Spotify и Яндекса; у альбомов она та же.

### 1.5.3

- Spotify: выбранная песня из плейлиста/альбома/любимых/рекомендаций играет она, а не первая: список сначала запускается (play), потом переход к песне (skipToIndex) — Spotify прыгает только внутри уже играющего списка.
- Spotify: перемотка колесом — позиция сдвигается сразу на каждый щелчок, запоздалые отчёты Spotify 0,7 с игнорируются.

### 1.6.0

- Spotify: список играет через Web API (PUT /me/player/play, context_uri + offset) — с выбранной песни и дальше по порядку списка. Нужно право user-modify-playback-state: старые входы видят «Войти снова (новые права)». Без него — прежний способ App Remote. Песни больше не ставятся в очередь Spotify (раньше там застревали любимые треки).
- Быстрые настройки: «Лайк» (♥/♡) для Spotify (App Remote addToLibrary) и Яндекс Музыки (likes/tracks add-multiple / remove); для Яндекса «Добавить в…» — список своих плейлистов, центр ставит отметку, MENU добавляет в отмеченные (change-relative, в конец) и закрывает.

### 1.6.1

- Spotify: старт списка по ссылке песни (offset.uri), а не по номеру — номер учитывал скрытые позиции (локальные файлы, подкасты, недоступные), и играла песня на несколько строк ниже.

### 1.7.0 — свои корпуса

- Темы корпуса из файла: CSS-подобный `monopod-theme { ключ: значение; }` (шаблон с описанием на двух языках — app/src/main/assets/monopod-theme-template.css). Часть 1 — корпус: градиент, отделка (gloss/brushed/matte), кант, стекло и рамка экрана, колесо, центр, значки статус-бара; картинки body-image (весь корпус) и menu-image (только главное меню, с вуалью menu-image-veil) — только в архиве .zip (css + картинки рядом, до 20 МБ). Часть 2 — готовые настройки (стиль, цвета, раскладка, эффект и сила, тёмный экран, шрифт, статус-бар), применяются один раз при выборе.
- Настройки → Внешний вид → Корпус: сначала свои корпуса, затем стандартные, затем «Скачать шаблон» (в Загрузки) и «+ Добавить» (системный выбор файла .css/.zip). Удержание центра на своём корпусе — «Обновить из файла» / «Удалить». Ошибки файла — всплывающим сообщением с причиной.
