# Monopod

[English](README.md) · **Русский**

Музыкальный плеер для Android в стиле iPod Classic. Всё управление — колесом прокрутки.

## Что умеет

**Медиатека**
- Музыка из выбранных папок (mp3, flac, m4a, ogg, opus, wav…), теги и обложки, плейлисты `.m3u`.
- Меню как на iPod: Плейлисты, Артисты → Альбомы → Песни, Альбомы, Песни, Жанры, Cover Flow. В списках альбомов справа обложка.
- Умные плейлисты («Топ-25», «Лучшие по рейтингу», «Недавно игравшие», «Недавно добавленные»), счётчик прослушиваний, рейтинг ★★★★★.
- Объединение альбомов, разбитых из-за разных исполнителей («A» и «A, B» → один альбом) — в Режиме разработчика.

**Воспроизведение**
- «Сейчас играет»: колесо — громкость, центр по кругу — перемотка, рейтинг, текст песни.
- Тексты из `.lrc` (UTF-8 или Windows-1251) или из тегов; синхронные идут вместе с песней.
- Cover Flow: 3D-обложки с отражениями; обложка с поворотом улетает на экран «Сейчас играет» в стиле iPod nano. Поверните телефон — Cover Flow на весь экран.
- Звук: без пауз между песнями, плавный переход, выравнивание громкости (ReplayGain), эквалайзер с пресетами iPod и своими, таймер сна.
- Уведомление, экран блокировки, кнопки гарнитуры и Bluetooth.
- Быстрые настройки по удержанию ⏯: перемешивание, повтор, таймер сна, плавный переход, эквалайзер, а для онлайн-музыки — «Лайк» и «Добавить в…».

**Онлайн-музыка** (Настройки → Режим разработчика → Онлайн музыка включает и выключает каждый сервис)
- **Spotify** через официальные Web API и App Remote SDK: медиатека и главная страница Spotify в Cover Flow. Музыку играет приложение Spotify (нужен Premium).
- **Яндекс Музыка** через неофициальный API (как в [Cassette](https://altlinux.space/rirusha/Cassette)): Моя волна, медиатека, персональные подборки. Песни играет сам Monopod — с эквалайзером, переходами и текстами.

**Внешний вид**
- Стиль iPod или Material; Material берёт цвета из обложки или обоев.
- Корпуса, акцентные цвета как в macOS, эффекты экрана (цветной LCD, ЭЛТ, монохром), две раскладки (Классика и Большой экран), три шрифта, тёмный экран.
- **Свои корпуса из файла темы**: CSS-подобный файл (или `.zip` с картинками для корпуса и главного меню). Настройки → Внешний вид → Корпус → «Скачать шаблон» / «+ Добавить». Шаблон с описанием каждого поля на русском и английском — [`app/src/main/assets/monopod-theme-template.css`](app/src/main/assets/monopod-theme-template.css). Или соберите тему наглядно в редакторе [`web/theme-editor/index.html`](web/theme-editor/index.html): откройте его в браузере, выберите цвета и картинки с живым превью и скачайте `.css` или `.zip`.
- Наклейки на корпус и шесть пресетов вида (Внешний вид → Пресеты), которые запоминают настройки и наклейки.

## Установка

APK — в [Releases](../../releases). Нужен Android 16 (API 36) или новее.

## Сборка

Нужны JDK 21 и Android SDK (platform 37). Путь к SDK — в `local.properties` (`sdk.dir=...`).

```bash
./gradlew assembleRelease
```

Готовый файл — в `app/build/outputs/apk/release/`. Он подписан отладочным ключом; чтобы публиковать свои сборки, пропишите свою подпись в `app/build.gradle.kts`.

Тесты логики (теги, плейлисты, тексты, звук, колесо, объединение альбомов, файлы тем):

```bash
./gradlew testDebugUnitTest
```

### Spotify

Своего приложения Spotify в Monopod нет: каждый входит через собственное бесплатное приложение разработчика Spotify (Spotify пускает в приложение в режиме разработки только добавленные в него аккаунты).

**В приложении:** Spotify → «Настроить Spotify» показывает всё, что нужно зарегистрировать на [developer.spotify.com/dashboard](https://developer.spotify.com/dashboard) — redirect URI `monopod://spotify-callback`, пакет `io.github.whyoolw.monopod` и SHA-1 установленного APK, с кнопками копирования — и принимает Client ID. В панели отметьте Web API и Android и добавьте свой аккаунт Spotify в User Management. Вход идёт по PKCE, секрет не нужен.

**В своей сборке** Client ID можно встроить через `local.properties` (в git не попадает):

```properties
spotify.clientId=0123456789abcdef0123456789abcdef
```

## О Яндекс Музыке

Поддержка Яндекс Музыки работает через неофициальный API с client id официального приложения, как и у других сторонних клиентов. Яндекс её не одобрял: она может перестать работать в любой момент и может противоречить правилам Яндекса. Используйте на свой риск; выключается в Режиме разработчика.
